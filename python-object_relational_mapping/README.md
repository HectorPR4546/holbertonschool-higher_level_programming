# Python Object-Relational Mapping

This project focuses on connecting Python applications to MySQL databases, exploring both direct SQL interaction using `MySQLdb` and Object-Relational Mapping (ORM) with `SQLAlchemy`.

## Learning Objectives

Through various tasks, this project aims to solidify understanding of:
- Connecting to MySQL from Python.
- Performing common database operations (SELECT, INSERT, UPDATE, DELETE) using Python.
- The concept of Object-Relational Mapping (ORM) and its benefits.
- Mapping Python classes to MySQL tables using SQLAlchemy.

## Project Structure

Each task is implemented in a separate Python script, demonstrating different aspects of database interaction:

- **MySQLdb Tasks:** Scripts demonstrating direct SQL queries, including filtering data, handling user input safely (SQL injection prevention), and joining tables.
- **SQLAlchemy ORM Tasks:** Scripts showcasing ORM principles, including defining database models (`State`, `City`), fetching, inserting, updating, and deleting records using SQLAlchemy's ORM capabilities.

## Requirements

All files adhere to the following standards:
- Interpreted/compiled on Ubuntu 20.04 LTS using Python 3.8.5.
- Executed with MySQLdb version 2.0.x and SQLAlchemy version 1.4.x.
- End with a new line.
- Start with `#!/usr/bin/python3`.
- Comply with `pycodestyle` (version 2.7.*).
- Are executable.
- Include comprehensive documentation for modules, classes, and functions.
