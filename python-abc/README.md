Python OOP – Abstract Class, Interface, Subclassing
Introduction

Welcome to this set of exercises aimed at honing your understanding and application of Object-Oriented Programming (OOP) concepts in Python. Through these exercises, you will delve into abstract classes, interfaces, duck typing, and subclassing standard base classes, among other essential OOP concepts. By the end, you should be proficient in applying OOP principles to design, implement, and test robust Python programs.
Learning Objectives

    Abstract Classes
    Understand and use abstract classes to define shared interfaces while enforcing class completeness.

    Interfaces and Duck Typing
    Grasp interface contracts and leverage duck typing to write flexible, protocol-oriented code.

    Subclassing Standard Base Classes
    Extend standard classes (like list, dict, iterator) to build specialized, customized data structures.

    Method Overriding
    Override base class methods to adapt or enhance inherited behavior.

    Multiple Inheritance
    Apply multiple inheritance techniques to model complex relationships between classes.

    Mixins
    Use mixins to compose behavior in a clean and reusable manner across unrelated classes.

Project Tasks

    Abstract Animal Class and its Subclasses
    Create an abstract Animal class and implement concrete subclasses such as Dog, Cat, and Bird.

    Shapes, Interfaces, and Duck Typing
    Design a Shape interface and use duck typing to manage polymorphic behavior in multiple shape implementations.

    Extending the Python List with Notifications
    Subclass Python’s built-in list class to create a custom list that logs or notifies upon changes.

    CountedIterator - Keeping Track of Iteration
    Create a custom iterator that keeps track of the number of elements iterated.

    The Enigmatic FlyingFish - Exploring Multiple Inheritance
    Implement a FlyingFish class that inherits behaviors from both Fish and Bird classes.

    The Mystical Dragon - Mastering Mixins
    Use mixins to add flight, fire-breathing, and speaking behaviors to a Dragon class.

Usage

Make any script executable:

chmod +x <filename.py>

Run the script:

./<filename.py>

You can also test with:

python3 <filename.py>
